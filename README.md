## Important Notice

This cluster is part of a **pilot project**. It is an experimental environment and may experience periods of instability or downtime. Please refer to the [User Guide](./docs/USER_GUIDE.md) for support details and usage expectations.

---

## Architecture Overview

The cluster is built using a modern, high-performance stack designed for educational research.

### Core Components
- **Scheduler**: Slurm (Simple Linux Utility for Resource Management)
- **Software Management**: Environment Modules
- **Compute Nodes**: High-performance CPU and GPU-enabled nodes
- **Filesystem**: Shared `/home` directory with high-speed local `/tmp` for compute tasks.

## Repository Structure

- `docs/`: Comprehensive user documentation and technical guides.
- `configs/`: (Planned) Configuration files for cluster settings and Slurm templates.
- `scripts/`: (Planned) Useful utility scripts for cluster maintenance and user tasks.
